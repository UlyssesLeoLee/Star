## 设计原则 (继承 docs/frontend-design.md §1.4)

- P-FE-1: 25 module 1:1 严格对齐 (不拆不并)
- P-FE-2: 6 SM 统一交互 (同一种 SmView 组件)
- P-FE-3: 不引入新聚合根 (前端只持有 UI 投影)
- P-FE-4: tenant 强制 (Topbar 显式显示,不可切换)
- P-FE-5: 25 page 全部 "use client" (MVP 阶段, V1 升级 RSC)
- P-FE-6: 设计 token 单一来源 (Tailwind theme)
- P-FE-7: Mock-first (Seed + Zustand, 切真后端时换 fetch)
- P-FE-8: 不画 UI 截图 (规范靠 token + token-driven 组件)
