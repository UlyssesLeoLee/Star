## ✨ 大師級 UI の特徴

### 🎨 視覚デザイン
- **深空グラデーション + ガラスモーフィズム** — `backdrop-filter: blur(20px) saturate(1.2)` で上質
- **9 フェーズ専用カラーパレット** — 紫→藍→青→翠→琥珀→橙→薔薇→桃→灰、V字左下から右上へグラデーション
- **Orb 浮遊背景** — 紫・青・琥珀の 3 つの大気オーブが 24-32 秒周期で微動
- **微細ノイズ + グリッド** — 技術系ダッシュボードの質感
- **3D perspective 傾斜** — 右側フェーズタブのホバーに `rotateY(-1.5deg)`
- **Glow halo** — アクティブフェーズの色光が全体に行き渡る

### 🛠️ 機能
- **5 ビュー切替** — Kanban / List / Timeline (工数ガントビュー)
- **5 状態カラム** — バックログ / ToDo / 進行中 (WIP) / レビュー (WIP) / 完了
- **WIP リミット表示** — 進行中 (WIP 3-5) / レビュー (WIP 2-3) を超過すると黄色警告
- **ドラッグ & ドロップ** — カードをカラム間移動、即時 localStorage 永続化
- **検索** — タイトル / 説明 / タグ全文検索 (`Ctrl+K`)
- **JSON エクスポート** — 右上ダウンロードボタンで `vmodel-kanban-YYYY-MM-DD.json`
- **自動スクロール** — フェーズ切替時、右側のアクティブタブが中央へスムーズスクロール
- **トースト通知** — すべての保存・削除・移動操作を右下から表示
- **完全永続化** — フェーズ構成 / タスク状態 / テーマ / 並び替えすべて `localStorage`

### 🎯 カスタマイズ（ユーザー独自の強み）
- **フェーズ追加** — ヘッダ右上の `+` ボタン → 名前・ふりがな・説明・アイコン・色を指定
- **フェーズ編集** — タブ右クリックまたは三点メニュー → 名前変更 / 色変更 / 複製
- **フェーズ移動** — 右クリックメニュー → 上へ / 下へ
- **フェーズ削除** — 右クリックメニュー → 削除（配下タスクは保持）
- **既定に戻す** — フッターの「既定に戻す」で V字モデル標準に復元

### ♿ アクセシビリティ
- `prefers-reduced-motion` 完全対応
- 暗色 / 明色テーマ切替
- キーボードナビゲーション（Escape でモーダル閉じる、Ctrl+K で検索）
- ARIA ラベル全箇所付与
- 4px ベースグリッド

## 🔄 永続化の仕様

`localStorage` キー：
- `vmodel-kanban-v1` — 内部使用
- `vmodel-phases-v1` — フェーズ構成（追加 / 削除 / 名前 / 色 / アイコン / 並び）
- `vmodel-tasks-v1` — タスク状態（カラム / オーナー / 追加タスク）
- `vmodel-theme-v1` — テーマ（dark / light）

**初期化**: ブラウザの DevTools Console で
```js
['vmodel-phases-v1','vmodel-tasks-v1','vmodel-theme-v1'].forEach(k => localStorage.removeItem(k));
location.reload();
```
